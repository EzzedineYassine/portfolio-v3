## ✨ Features

- **🌍 Full Multilingual Support (i18n):**
  - Seamless instant switching across 4 languages: **English**, **Français**, **Deutsch**, and **العربية**.
  - Bidirectional layout with full native **RTL (Right-to-Left)** support for Arabic.
  - Persistent language preference saved in `localStorage`.
- **📄 Dynamic Localized ATS Resumes:**
  - Integrated 1-page modern ATS-friendly CV automatically served in the active language (`cv-en.pdf`, `cv-fr.pdf`, `cv-de.pdf`, `cv-ar.pdf`).
- **💻 Featured Project Showcase:**
  - **Phantom Stickers:** Full-stack e-commerce platform built with React, Vite, and Supabase with admin CRUD and authentication.
  - **BI Customer Segmentation:** Retail data analytics pipeline with RFM, K-Means clustering, Apriori association rules, and PyQt5.
  - **Movie Recommender System:** Content-based recommendation engine built with Scikit-learn, CountVectorizer, and Cosine Similarity.
  - **Moto Parts Stock Manager:** Multi-platform inventory management software built with Flutter, SQLite, and Supabase.
  - **Hotel Amira:** Dynamic hospitality web platform for booking and room availability tracking.
- **⏳ Career & Academic Timeline:**
  - Interactive filterable timeline detailing academic milestones (FSEG Nabeul, Baccalauréat) and industry experience (Tunisie Telecom application development internship, client projects).
- **⚡ Performance & Smooth Experience:**
  - High-performance asset loading, optimized video streams, interactive dynamic typing animation, and IntersectionObserver-driven scroll reveals.
  - Responsive dark cosmic aesthetic matching mobile, tablet, and desktop viewports.

- **Frontend:** HTML5, Modern CSS3 (CSS Grid & Flexbox, custom properties, glassmorphism), Vanilla JavaScript (ES6+ Modules)

- **Deployment & Hosting:** Vercel (Edge Network, continuous deployment via GitHub)

## 🚀 Local Development

Clone and run locally without requiring any npm build steps:

```bash
# Clone the repository
git clone https://github.com/EzzedineYassine/yassin-portfolio-v3.git

# Navigate into project directory
cd yassin-portfolio-v3

# Serve using any local static web server
python -m http.server 3000
# or
npx serve .
```

Open `http://localhost:3000` in your browser.
